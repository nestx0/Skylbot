AYUDA

Preguntas frecuentes.

Respuestas sobre Skylbot, su instalación y cómo utilizarlo.

¿Qué es Skylbot?

Es un bot comunitario de Discord con minijuegos, economía virtual, coleccionables, combates, encuestas y chat con IA.

¿Cómo añado Skylbot a mi servidor?

Usa el botón «Añadir Skylbot», selecciona un servidor en Discord y confirma los permisos. Para que funcione, el administrador debe haber configurado el ID de la aplicación en la web.

¿Necesito GitHub?

No. La invitación se completa desde Discord. GitHub solo se ofrece para consultar el código o reportar errores.

¿Cuál es el prefijo del bot?

Actualmente es el asterisco *. Escribe *guide para consultar los comandos disponibles.

¿Tiene coste?

Los juegos utilizan moneda virtual. El repositorio no incluye un sistema de pagos o suscripciones para los usuarios del bot.

¿Necesito permisos especiales?

Para añadirlo necesitas permisos para gestionar aplicaciones en el servidor. Revisa los permisos solicitados en la pantalla oficial de Discord antes de autorizar.

¿Funciona en cualquier servidor?

Por ahora no se puede garantizar. El código incluye identificadores de canales, roles y emojis específicos del servidor original. Algunos componentes también necesitan preparar la base de datos.

¿Cómo se usan los comandos?

Escríbelos en Discord. Por ejemplo, *work consigue moneda virtual, *balance muestra tu saldo y *blackjack 100 inicia una partida.

¿Qué datos utiliza?

El bot almacena identificadores de usuario, saldos e inventarios en SQLite. El chat de IA remite mensajes a un proveedor externo y conserva un historial temporal en memoria. Consulta Privacidad.

¿Dónde reporto un problema?

En la página de incidencias del proyecto.
