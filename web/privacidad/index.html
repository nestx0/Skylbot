1. La página web

Este sitio es una web estática para consultar las funciones de Skylbot y acceder a su invitación oficial de Discord. El código de la web no establece cuentas de usuario, no solicita contraseñas, no envía formularios y no integra cookies analíticas ni de publicidad. La búsqueda de comandos, los botones de copia y la demostración interactiva de comandos funcionan localmente en tu navegador. La web utiliza fuentes del sistema y no solicita recursos tipográficos de terceros.

El proveedor de alojamiento podría tratar datos técnicos de conexión, como dirección IP, fecha, hora y agente de usuario, según sus propias condiciones. Es necesario identificar al proveedor antes de publicar el sitio.

2. Datos que utiliza el bot

Según el código público revisado, Skylbot almacena en una base de datos SQLite identificadores de usuarios de Discord, saldos de moneda virtual y datos de inventario de personajes. El bot accede además a los mensajes y eventos necesarios para ejecutar sus comandos, enviar respuestas y realizar acciones en canales.

Estos datos corresponden al funcionamiento del bot, no a la visita de esta web. No se puede confirmar desde la web un periodo de conservación ni un procedimiento automatizado de supresión en el servidor del bot.

3. Uso del asistente de IA

Si usas *ai, el código del bot envía el texto de la consulta, un nombre de usuario y contexto reciente de conversación a un proveedor externo de modelos de lenguaje (Z.ai / GLM). Mantiene historial de conversación en memoria de la aplicación mientras se ejecuta y ofrece *clear para borrar ese historial temporal asociado al nombre de usuario.

Evita introducir datos personales o información confidencial en chats con el bot.

4. Servicios de terceros

Al pulsar «Invitar», sales de esta web y accedes al dominio discord.com, donde se aplican las condiciones y la política de privacidad de Discord. El bot también se integra con el proveedor de IA y puede consumir otras API externas para funciones como los chistes.

5. Control, solicitudes y contacto

Antes de publicar un servicio abierto al público deben identificarse sus responsables, los medios de contacto y, cuando corresponda, las bases jurídicas y plazos de conservación de los datos. El repositorio público no permite verificar toda esa información, por lo que este texto es una descripción técnica preliminar y no sustituye a una política de privacidad completa del operador.

Por ahora, las incidencias y consultas generales sobre el proyecto pueden plantearse en GitHub Issues. El operador del servicio deberá proporcionar un canal adecuado para ejercer derechos de privacidad.

Este documento está redactado a partir del funcionamiento observable del repositorio. Requiere completar los datos del responsable y del alojamiento antes de un lanzamiento público.
